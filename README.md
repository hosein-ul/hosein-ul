### 📖 About Me & Engineering Focus

I am an independent **Web3 systems architect and smart contract developer**, active on-chain since 2021. My work is focused on the architecture of **non-custodial financial rails**, **confidential state execution** via Fully Homomorphic Encryption (FHEVM), and **high-throughput L2 exchange infrastructure**.

Rather than relying on centralized intermediaries or custodial escrows, I design decentralized protocols where liquidity moves directly from payer to merchant, where smart contracts compute over fully encrypted balances without revealing private financial data to the mempool, and where autonomous AI agents can safely simulate transactions before committing capital on-chain.

- **Non-Custodial Stablecoin Rails:** Peer-to-merchant payment rails where every transaction is assigned a deterministic, single-use address and settles straight to the recipient's wallet with zero escrow custody. Multi-token settlement (native USDC and EURC) deployed on low-latency networks like Circle Arc.
- **Confidential On-Chain Finance (FHEVM & ERC-7984):** Application-level cryptographic privacy on Ethereum using Zama's Fully Homomorphic Encryption Virtual Machine and the ERC-7984 confidential token standard. Enables contracts to perform arithmetic and balance transfers directly on encrypted ciphertexts (`euint64`), preserving total user privacy without sacrificing EVM composability.
- **High-Throughput L2 DEX Infrastructure:** Production-grade decentralized trading platforms engineered on the Arbitrum Nitro L2 stack (such as Optima DEX on Robinhood Chain Mainnet). Combines concentrated liquidity (Uniswap V3), RFQ off-chain quote settlement for real-world equity tokens, and sub-second execution with Next.js 16 and Viem.
- **Autonomous Agent Safety & x402 Micropayments:** Pre-execution bytecode simulation engines for autonomous AI agents handling on-chain treasuries. Calculates algorithmic 0–100 transaction risk scores before any private key signs, paired with HTTP 402 (x402) micropayment rails for agent-to-agent (A2A) commerce.
